# Adhisha Khandelwal — Portfolio

A responsive personal portfolio website built using **HTML and CSS only**. It is ready to publish with GitHub Pages; no build tools, frameworks, or JavaScript are required.

## Files

- `index.html` — website content
- `style.css` — styling and responsive layout
- `assets/adhisha-khandelwal-photo.jpeg` — profile photograph
- `assets/Adhisha_Khandelwal_Resume.pdf` — downloadable resume
- `.nojekyll` — disables unnecessary Jekyll processing on GitHub Pages

## Publish with GitHub Pages

1. Create a new repository on GitHub.
2. Upload all files and folders from this project, keeping the `assets` folder structure intact.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then click **Save**.
6. Wait for GitHub Pages to publish the site. Your public website URL will appear in the Pages settings.

The photo and resume links use relative paths, so they work on GitHub Pages when the folder structure is preserved.
